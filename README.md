# Pink October — Watan The Seed of Love

Bilingual (English/Arabic) breast cancer awareness donation page.

## Deploy

```bash
npm install -g wrangler
wrangler deploy
```

This deploys a Worker named `pink-october` and attaches the custom domain
`pinkoctober.watantheseedoflove.org` automatically.

## Features

- Full-screen hero with your Cloudflare Images delivery URL
- Bilingual content (English + Arabic with RTL)
- Donation methods: QR code (PayPal), Zelle, Apple Pay, Cash App
- Contact phone numbers (clickable)
- Donate Now button linking to PayPal
- Visa, Mastercard, AMEX, Discover, PayPal logos
- Responsive design with scroll animations
